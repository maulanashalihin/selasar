# This deploys Selasar with: Bun (app) + ClickHouse (analytics, native binary)
# HTTPS via Cloudflare proxy + Origin Rule (not Caddy/nginx).

Deploy my Selasar app on my VPS using systemd (no Docker). Here are the details:

- SSH: ssh USER@SERVER_IP
- GitHub repo: https://github.com/YOUR_USER/YOUR_REPO.git
- Domain: your-domain.com (or "none" if no domain yet)
- Install path: /opt/selasar
- App port: APP_PORT (e.g. 4000)

Steps:
1. SSH into the server. Check OS, RAM, disk space.
2. Install Bun: curl -fsSL https://bun.sh/install | bash
   Then symlink: sudo ln -sf ~/.bun/bin/bun /usr/local/bin/bun
   And: sudo ln -sf ~/.bun/bin/bunx /usr/local/bin/bunx
3. Install ClickHouse (native binary, not Docker):
   curl -fsSL https://clickhouse.com/ | bash
   sudo ./clickhouse install
4. Create systemd service for ClickHouse at /etc/systemd/system/clickhouse.service:
   Type=simple, User=clickhouse, ExecStart=/usr/bin/clickhouse-server --config-file /etc/clickhouse-server/config.xml
   ExecStop=/usr/bin/clickhouse-client --query 'SYSTEM SHUTDOWN'
   Restart=on-failure, LimitNOFILE=500000
   Enable and start it. Verify: curl http://localhost:8123/ping → "Ok."
5. Check if the app port is already in use (ss -tlnp | grep APP_PORT).
   If it is, pick the next available port.
6. Clone the repo: sudo mkdir -p /opt/selasar && sudo chown $USER:$USER /opt/selasar
   cd /opt/selasar && git clone <repo> .
7. bun install && bun run build
8. Create .env in the install path with these required keys:
   PORT=<chosen port>
   NODE_ENV=production
   APP_URL=https://your-domain.com (or http://SERVER_IP:<port> if no domain)
   DATABASE_PATH=./data/app.sqlite
   SSR=true
   MAIL_DRIVER=log
   MAIL_FROM=no-reply@example.com
   CLICKHOUSE_URL=http://localhost:8123
   CLICKHOUSE_DB=analytics
   Leave GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, RESEND_API_KEY empty if unused.
   Create data dir: mkdir -p data
9. Init ClickHouse schema: bun run scripts/init-clickhouse.ts
10. Read the "name" field from package.json — that's the service name.
    Create a systemd unit at /etc/systemd/system/<name>.service:
    Type=simple, User=$USER, WorkingDirectory=/opt/selasar
    EnvironmentFile=/opt/selasar/.env
    ExecStart=/usr/local/bin/bun src/index.ts
    Restart=on-failure, RestartSec=3
    Enable and start it.
11. Verify: curl http://localhost:<port>/health should return 200.
12. Seed an admin user: bun run db:seed admin@example.com admin123 admin
13. Configure UFW firewall:
    - If using Cloudflare: allow the app port ONLY from Cloudflare IP ranges
      (15 IPv4 + 7 IPv6 ranges from https://cloudflare.com/ips/)
    - If no Cloudflare: sudo ufw allow <port>/tcp
14. If using Cloudflare (recommended for HTTPS):
    - Create a DNS A record for your-domain.com → server IP (proxied/orange cloud)
    - Add an Origin Rule: if http.host eq "your-domain.com" → route to port <chosen port>
    - Set SSL mode to Flexible (Cloudflare terminates HTTPS, origin gets HTTP)
15. Save these lines to deploy.env in my LOCAL project root (NOT on the server).
    Add deploy.env to .gitignore if not already:
    ```
    DEPLOY_SSH=<USER@SERVER_IP>
    DEPLOY_PATH=<install path>
    DEPLOY_PORT=<chosen port>
    DEPLOY_SERVICE=<service name from step 10>
    DEPLOY_URL=https://your-domain.com
    ```
16. Tell me: the URL, port used, service status, ClickHouse status, and any issues.
