# The docker-compose.yml handles both containers — no manual ClickHouse setup.

Deploy my Selasar app on my VPS using Docker Compose. Here are the details:

- SSH: ssh USER@SERVER_IP
- GitHub repo: https://github.com/YOUR_USER/YOUR_REPO.git
- Domain: your-domain.com (or "none" if no domain yet)
- Install path: /opt/selasar
- App port: APP_PORT (e.g. 4000)

Steps:
1. SSH into the server. Check OS, RAM, disk space.
2. Install Docker and Docker Compose if not already installed.
3. Check if the app port is already in use (ss -tlnp | grep APP_PORT).
   If it is, pick the next available port.
4. Clone the repo: sudo mkdir -p /opt/selasar && sudo chown $USER:$USER /opt/selasar
   cd /opt/selasar && git clone <repo> .
5. Create .env in the install path with these required keys:
   PORT=<chosen port>
   NODE_ENV=production
   APP_URL=https://your-domain.com (or http://SERVER_IP:<port> if no domain)
   DATABASE_PATH=./data/app.sqlite
   SSR=true
   MAIL_DRIVER=log
   MAIL_FROM=no-reply@example.com
   Leave CLICKHOUSE_URL and CLICKHOUSE_DB unset — docker-compose.yml sets them
   automatically (http://clickhouse:8123, analytics).
   Leave GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, RESEND_API_KEY empty if unused.
6. Run: docker compose up -d --build
   This starts both the app container and ClickHouse container.
7. Wait for containers to be healthy: docker compose ps
   Both "app" and "clickhouse" should show "healthy".
8. Init ClickHouse schema (run inside the app container):
   docker compose exec app bun run scripts/init-clickhouse.ts
9. Verify: curl http://localhost:<port>/health should return 200.
   Also confirm the app runs as non-root: docker compose exec app id
   should output uid=1000(bun), NOT uid=0(root).
10. Seed an admin user: docker compose exec app bun run db:seed admin@example.com admin123 admin
11. Configure UFW firewall:
    - If using Cloudflare: allow the app port ONLY from Cloudflare IP ranges
      (15 IPv4 + 7 IPv6 ranges from https://cloudflare.com/ips/)
    - If no Cloudflare: sudo ufw allow <port>/tcp
12. If using Cloudflare (recommended for HTTPS):
    - Create a DNS A record for your-domain.com → server IP (proxied/orange cloud)
    - Add an Origin Rule: if http.host eq "your-domain.com" → route to port <chosen port>
    - Set SSL mode to Flexible (Cloudflare terminates HTTPS, origin gets HTTP)
13. Save these lines to deploy.env in my LOCAL project root (NOT on the server).
    Add deploy.env to .gitignore if not already:
    ```
    DEPLOY_SSH=<USER@SERVER_IP>
    DEPLOY_PATH=<install path>
    DEPLOY_PORT=<chosen port>
    DEPLOY_URL=https://your-domain.com
    ```
14. Tell me: the URL, port used, container status, and any issues.
